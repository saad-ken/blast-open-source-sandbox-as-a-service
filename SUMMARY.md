**Idea source:** [Hacker News Show HN](https://github.com/stanford-mast/blast)

**Why picked:** Blast – Open-source sandbox-as-a-service: A simple tool to allow users to create and run their own sandbox environments locally, without needing to set up a paid service or a database.
